Astuces pour les projets complexes

  • Next.js : Glissez un ZIP du repo ou le dossier racine, SitePlan crée un sitemap.ts prêt pour src/app/, y compris pour les routes dynamiques [slug].
  • + 50 000 URLs : utilisez l'export sitemap-index.xml pour un fractionnement automatique.
  • Multilingue : activez hreflang dans les options avancées.
  • Ajoutez Sitemap: https://example.com/sitemap.xml à votre robots.txt (généré automatiquement).
